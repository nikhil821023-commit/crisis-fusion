
# Multimodal Disaster Information Classification Using Text-Image Fusion

## 1. Introduction

Natural disasters generate large amounts of information through social media.
This information contains both textual and visual signals that can help identify
the type and severity of disaster-related situations.

This project investigates multimodal disaster classification using textual and
image information from the CrisisMMD dataset. The project evaluates individual
text and image models and then combines their predictions using score-level
fusion.

The experiments cover four tasks:

1. Task 1a — Informativeness classification
2. Task 1b — Disaster type classification
3. Task 2 — Humanitarian information classification
4. Task 3 — Damage severity classification

A multimodal cross-modal fusion architecture was also evaluated for Task 1a.

---

## 2. Dataset

The experiments use the CrisisMMD v2.0 dataset.

The dataset contains disaster-related social media posts with both text and
images.

The four classification tasks used in this project are:

### Task 1a — Informativeness

- Informative
- Not informative

### Task 1b — Disaster Type

- Earthquake
- Flood
- Hurricane
- Non-informative
- Wildfire

### Task 2 — Humanitarian Information

- Affected individuals
- Infrastructure and utility damage
- Injured or dead people
- Missing or found people
- Not humanitarian
- Other relevant information
- Rescue, volunteering or donation effort
- Vehicle damage

### Task 3 — Damage Severity

- Little or no damage
- Mild damage
- Severe damage

---

## 3. Methodology

The project evaluates text and image modalities separately before combining
their predictions.

### Text models

Different transformer-based text models were evaluated:

- BERT
- RoBERTa
- BERTweet

### Image model

The image experiments use Vision Transformer (ViT).

### Score-level fusion

For score fusion, the probability distributions generated by the text and image
models are combined using equal weighting.

The final probability is:

P(final) = 0.5 × P(text) + 0.5 × P(image)

The class with the highest final probability is selected as the prediction.

---

## 4. Experimental Results

### 4.1 Task 1a — Informativeness

The best unimodal model was RoBERTa with an accuracy of 87.03%.

Combining RoBERTa and ViT using score-level fusion increased the accuracy to
91.13%.

The weighted F1 score increased from 86.83% to 90.98%.

Therefore, score fusion improved accuracy by 4.11 percentage points.

---

### 4.2 Task 1b — Disaster Type

RoBERTa achieved the best unimodal accuracy of 86.57%.

The RoBERTa + ViT score-fusion model achieved 90.29% accuracy.

Weighted F1 increased from 86.30% to 90.23%.

This corresponds to a 3.72 percentage-point improvement in accuracy.

---

### 4.3 Task 2 — Humanitarian Information

BERTweet achieved the best unimodal accuracy of 82.30%.

ViT achieved 78.12%.

Combining BERTweet and ViT using score fusion produced an accuracy of
86.28%.

Weighted F1 increased from 82.25% to 85.76%.

This produced a 3.98 percentage-point improvement in accuracy.

A live Gradio demonstration was also implemented for this task.

The demonstration accepts a disaster-related text and an image and displays
the confidence distribution across the eight humanitarian information classes.

---

### 4.4 Task 3 — Damage Severity

Task 3 was substantially more difficult than the other tasks.

The best unimodal result was obtained by ViT:

- Accuracy: 64.27%
- Weighted F1: 52.55%

Score fusion produced:

- Accuracy: 63.14%
- Weighted F1: 49.41%

Therefore, score fusion did not improve Task 3.

The result suggests that the damage-severity task is more challenging and is
strongly affected by class imbalance.

---

## 5. Final Comparison

| Task | Best Unimodal Accuracy | Best Unimodal F1 | Score Fusion Accuracy | Score Fusion F1 |
|------|-----------------------:|------------------:|----------------------:|----------------:|
| Task 1a | 87.03% | 86.83% | 91.13% | 90.98% |
| Task 1b | 86.57% | 86.30% | 90.29% | 90.23% |
| Task 2 | 82.30% | 82.25% | 86.28% | 85.76% |
| Task 3 | 64.27% | 52.55% | 63.14% | 49.41% |

Score fusion improved the first three tasks but did not improve Task 3.

---

## 6. Cross-Modal Fusion

A separate cross-modal fusion architecture was evaluated for Task 1a.

The architecture combines textual and visual representations using
cross-modal attention followed by multimodal self-attention.

The Task 1a checkpoint achieved:

- Accuracy: 89.44%
- Weighted F1: 89.29%

The cross-modal fusion model therefore performed better than the individual
unimodal models, although the simple 50/50 score-fusion approach achieved the
highest Task 1a result of 91.13%.

---

## 7. Ablation Study

Inference-time diagnostics were performed on the Task 1a cross-modal fusion
model.

The full fusion model achieved 89.50% accuracy.

Removing cross-modal attention reduced performance to approximately 86.18%.

Removing self-attention reduced performance to approximately 87.74%.

Text-only and image-only inference produced lower performance than the complete
fusion model.

These results indicate that combining information from both modalities is
useful for the Task 1a classification problem.

---

## 8. Task 3 Improvement Experiments

Additional experiments were conducted to improve Task 3.

### Baseline

- Accuracy: 66.35%
- Macro F1: 45.64%

### Class weights

- Accuracy: 66.73%
- Macro F1: 55.13%

Class weighting substantially improved the macro F1 score.

### Class weights + augmentation

- Accuracy: 65.78%
- Macro F1: 56.66%

This produced the best macro F1 among the Task 3 improvement experiments.

### Class weights + augmentation + oversampling

- Accuracy: 53.50%
- Macro F1: 51.49%

Oversampling together with class weighting and augmentation reduced the
overall accuracy substantially.

The experiments suggest that class weighting and augmentation were more useful
than aggressive oversampling for this dataset.

---

## 9. Demonstration

A Gradio-based demonstration was implemented.

The Task 2 demonstration accepts:

- Disaster-related text
- Disaster image

The text is processed using BERTweet and the image is processed using ViT.
Their probability distributions are combined using 50/50 score fusion.

The system then displays the confidence scores for all eight humanitarian
information categories.

For example, one demonstration produced:

**Rescue, volunteering or donation effort — 59%**

followed by infrastructure and utility damage at 16%.

---

## 10. Discussion

The experiments show that multimodal information can improve disaster-related
classification.

Score-level fusion improved three out of the four evaluated tasks:

- Task 1a: +4.11 percentage points
- Task 1b: +3.72 percentage points
- Task 2: +3.98 percentage points

However, Task 3 remained challenging.

The Task 3 results indicate that overall accuracy alone is not sufficient for
evaluating an imbalanced classification problem. Macro F1 and balanced
accuracy provide additional information about minority-class performance.

---

## 11. Limitations

The current experiments have several limitations.

1. Equal 50/50 score fusion was used instead of learning the optimal fusion
   weights.
2. Task 3 remains affected by class imbalance.
3. The cross-modal fusion experiment was completed for Task 1a but was not
   completed for all four tasks.
4. The demonstration depends on pretrained Hugging Face models and trained
   checkpoints.
5. The current demonstration is intended as a research prototype rather than
   a production disaster-response system.

---

## 12. Future Work

Future improvements could include:

- Learning adaptive fusion weights.
- Training the complete cross-modal architecture on additional tasks.
- Better handling of minority classes in Task 3.
- More advanced data augmentation.
- Larger-scale hyperparameter tuning.
- Real-time disaster information processing.
- Deployment of the multimodal model as a web service.
- Integration with real-time disaster monitoring systems.

---

## 13. Conclusion

This project evaluated multimodal disaster classification using text and image
information from CrisisMMD.

The experiments demonstrated that score-level fusion can substantially improve
performance for informativeness, disaster type and humanitarian information
classification.

The best score-fusion accuracies were:

- 91.13% for Task 1a
- 90.29% for Task 1b
- 86.28% for Task 2

Task 3 remained challenging, highlighting the importance of class imbalance
handling and class-aware evaluation.

A working Gradio demonstration was also developed for humanitarian information
classification, providing an interactive demonstration of the multimodal
prediction system.
